# DUL variants

Generated by [`../../code/make_dul_variants.py`](../../code/make_dul_variants.py)
from the original DUL. Each file records the removed axioms in an `rdfs:comment`
on the ontology header.

| File | Removed | Use with |
|---|---|---|
| `DUL-lite.ttl` | `dul:associatedWith` transitivity, symmetry and self-inverse axiom | `ecmo-graphdb-benchmark.sh --dul-lite` |
| `DUL-flat.ttl` | the same for every DUL property: no transitive, symmetric or self-inverse property is left | `ecmo-graphdb-benchmark.sh --dul-flat` |

Everything else is kept: hierarchy, domains and ranges, inverses between
distinct properties, property chains, disjointness.

Why: with full DUL, almost every ECMO property is a subproperty of the
transitive and symmetric `dul:associatedWith`, so owl-horst, owl-max and
owl2-rl materialise an `associatedWith` clique of about 16.8M triples.

The disjointness violations of ECMO + DUL are the same with all three versions
(see `reasoning-capability-test/graphdb/results/ecmo-inconsistencies.md`).

To regenerate:

```bash
python ../../code/make_dul_variants.py                       # downloads DUL
python ../../code/make_dul_variants.py ../ecmo-deps/DUL.owl
```
